# 三相モーター攻略 v0.1

第二種電気工事士向けの、三相誘導電動機を7問で反復する独立した静的Webアプリです。公式過去問ではありません。HTML / CSS / JavaScriptのみで動作し、ビルドや依存パッケージのインストールは不要です。

## 起動

このフォルダーの `index.html` をブラウザーで開いてください。静的Webサーバーでもそのまま配信できます。学習記録はブラウザー・配信元ごとに保存されるため、ファイルで開いた記録とWeb配信した記録は共有されません。

## 構成

- `engine.js`：問題、学習判定、状態検証。選択肢IDで正誤を判定。
- `app.js`：画面、SVG配線操作、localStorage、効果音。
- `style.css`：スマートフォン / PC表示、動きの軽減対応。
- `engine.test.cjs`：Node.js組み込みテストによる学習ロジック検証。

## テスト

このフォルダーで `node --test engine.test.cjs storage.test.cjs` を実行します。

固定順、誤答再挑戦、連続パーフェクトと解放、ランダム出題、3組の配線交換、解答直後と結果の保存復元、二重集計防止、不正データを検証します。

保存拒否・容量制限・リセット範囲は模擬環境でも検証します。ブラウザーでPCおよび幅375pxの表示、7問の回答、キーボード操作、配線の選択解除と3本目拒否、誤答・正解・結果画面の再読み込みを確認済みです。実機スマートフォンと実際のスピーカーでの効果音再生は未確認です。

## 保存

キーは `three-phase-motor-v01`、schemaVersionは1です。保存失敗時もメモリー上で練習を継続します。リセットは確認後にこのキーだけを削除します。音は初期OFFです。誤答数は再挑戦時を含む誤答の回数、初回正解数は各周・各問の最初の解答が正解だった回数です。連続パーフェクト表示は2で上限とします。

中断した周はホームの「続きから練習」で再開します。進行中の周がある間、新しい周は開始できません。再読み込みは解答後の解説や配線選択状態も復元します。

資料46〜47ページの元画像は今回の作業には含まれていないため、問題文・解説は提供された要件定義書に基づいています。
