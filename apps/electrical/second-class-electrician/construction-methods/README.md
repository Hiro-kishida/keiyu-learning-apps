# 施設場所と工事種別トレーニング v0.1

第二種電気工事士「施工法1」の独立した静的学習アプリ。提供された教材の本文・表・問題・解答解説を照合して作成。外部通信、ログイン、依存ライブラリー、ビルド処理は不要。

## 実行

`index.html` をブラウザーで開くか、フォルダーを静的Webサーバーで配信します。

## 練習

- 場所と記号の基礎：6区分と◎・○・□の意味を学ぶ、独自の9問。
- 手順つき練習：教材9問を各3段階で解く。正解した段階を残して進む。
- 9問チャレンジ：教材の問題・選択肢。最初は資料非表示。任意で表・ヒントを開ける。
- 固定9問を2周連続で手助けなし・初回全問正解すると、順序だけを変えるランダムモードを永続解放。
- 各モード終了時、誤答した問題だけを同じ形式で復習できる。

固定チャレンジの誤答・資料やヒントの使用は連続回数を即座に0にする。他モードは固定連続回数を変更しない。手順モードでは一つでも段階を誤ると、その問題は再挑戦扱い。表を常時表示する基礎・手順モードは手助けありとして記録。音は初期OFF、全問初回正解時のみ短い紙吹雪。動きの軽減設定に対応。

## 教材データの扱い

問題・選択肢の語句と条件を維持し、改行・字間・括弧・数字の字形のみ画面向けに整形。独自の基礎問題と手順の小問は原文と区別。教材写真や手書き部分は配布しない。

表の列順は「展開・乾燥」「展開・湿気」「点検できる隠ぺい・乾燥」「同・湿気」「点検できない隠ぺい・乾燥」「同・湿気」。スマートフォンでは6区分から一つを選び、その列を表示。空欄は「— 施工できない」と明示。◎・○・□を単純な二値判定に変換しない。

- ◎：施工できる。水気のある場所は湿気のある場所に含まれる。
- ○：使用電圧300 V以下。
- □：使用電圧300 V以下。300 Vを超える場合は、電動機に接続する部分で可とう性を必要とする部分に限る。場所の条件も必要。

### 確認済みの教材との差

問3の教材解説にある「この場所にもすべてのダクト工事が禁止」は、セルラダクト・フロアダクトの条件つき印と矛盾する。ユーザー確認済みの方針により「バスダクト工事は、点検できない隠ぺい場所には施工できない」と説明し、全ダクトへの一般化を避けた。問題文・選択肢・正解は変更しない。

問8は、引込線取付点から引込口に至る屋側電線路・木造の造営物・展開した場所という条件を維持。木造建物全般の禁止へ広げない。問9は、がいし引き・300 V以下の屋内臨時配線・施工完了日から4か月以内に限定。両問は場所の表とは別の資料を表示する。

## 保存・検証

localStorageキー：`construction-methods-v01`。問題・段階・誤答・手助け・結果状態、音設定、連続回数、解放、完了周数と問題別成績を保存。結果の二重集計を防止し、壊れたデータは初期化。保存できない環境でも継続可能。リセットは確認後にこのキーだけを削除。他の学習アプリとは共有しない。

テスト：このフォルダーで `node --test engine.test.cjs`。
